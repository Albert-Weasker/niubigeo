# 关键词持续侦测（NEW / BETA）

关键词持续侦测与域名认知是同一工作台中的两个独立模块。关键词可以完全自定义，不需要先创建域名监测范围。

## 当前能力

- 单个添加关键词或批量导入，每行一个关键词。
- 从 AI Coding、SaaS / Product、GEO、品牌对比案例一键添加。
- 标记 Discovery、Alternative、Comparison、Brand、Use case 类型。
- 频率支持每小时、每天、每周。
- 可选填写监控品牌和别名，例如“牛逼GEO”、`NiubiGEO`。
- 每次运行单独保存回答、模型、提及品牌、位置和引用历史。

完成两次检测后会显示 **变化预览（Diff View）**，对比前后快照中的推荐对象、提及位置，以及新增或移除的来源链接。

页面显示为 **关键词持续侦测 NEW / BETA**。Beta 阶段接口和统计方式可能调整。竞争对手侦测面板暂不包含在本阶段。

临时浏览器 Key 不能交给独立 scheduler worker 使用；自托管定时运行需要配置服务端模型 Key。模型执行仍使用工作台中已保存的模型配置。

## 监控控制与证据

- Worker 面板显示心跳、最近轮询与最近执行。心跳过期不能证明任务已执行。请用与 Web 服务相同的数据目录及服务端密钥启动 `npm run schedule:worker`。每个关键词显示下次执行时间，配置失败也保留历史记录。
- 在“设置”中添加最多 20 个标签，并按标签筛选。标签不改变测量分数。
- 每个模型可采样 **1–10 次**，默认 1 次；单次观测最多请求模型 100 次。表单按关键词估算模型调用量，服务商重试及联网可能额外计费，金额未知。历史分别展示成功样本中的提及次数、失败次数，以及推荐对象和来源出现次数。这些是观测结果，不代表统计保证。
- 可从最新历史记录中只重试某个模型的失败样本。成功样本和原始失败记录都会保留，重试产生关联的新记录。缺少运行条件的旧记录不支持这种重试。
- Diff 核对提示词、语言、品牌与别名、采样次数、模型及服务商、返回的模型版本和联网配置。条件变化、失败或缺失的样本会被排除；旧记录及重试快照会提示可比性限制，未检测到变化不等于可见度稳定。
- “导出 CSV”固定导出页面当前查看的两条记录，包含日期、模型与样本、提及、位置、推荐对象、来源链接、失败及可比性提示。CSV 中的位置变化需要结合提示解释。

这些改进已加入源码；使用版本化 Docker 镜像时，需要选择包含这些改进的发布版本。无需迁移历史数据。
