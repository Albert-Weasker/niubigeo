# NiubiGEO v0.3.1

## Fixes / 修复

- Restore manual Keyword Monitoring with the standard provider executor. Reject empty or invalid keyword batches before any monitor is written; keep validation errors visible in the form.
- Repair keyword page script syntax and template selection. Reuse the selected OpenRouter model for auxiliary analysis.
- Align Compose with the current release and add English Docker instructions with storage migration guidance.
- Preserve localhost binding for direct source startup; Docker explicitly uses HOST=0.0.0.0 inside the container so published ports work.
- Include the main-branch concurrency, stale-lock recovery, baseline, statistics, notification timeout and failed-snapshot comparison fixes.

修复关键词手动运行、空白批次校验、页面脚本和模板；OpenRouter 辅助分析沿用选定模型。统一 Compose 版本、补充英文部署指引，并修复容器监听地址。包含主分支已合并的并发锁、基线、统计、通知超时与失败快照比较修复。

## Docker

```bash
docker pull ghcr.io/albert-weasker/niubigeo:v0.3.1
```

The amd64 and arm64 images are verified before publishing. After successful verification, the Docker tags `v0.3.0` and `latest` point to the same corrected v0.3.1 image. Its package version and OCI version remain v0.3.1. The original Git tag v0.3.0 is unchanged. Existing containers must be pulled and recreated to update; data volumes must be retained.

两种架构验证通过后，Docker 的 `v0.3.0` 和 `latest` 标签也指向修复后的 v0.3.1 镜像。镜像内部版本仍为 v0.3.1，原 Git tag v0.3.0 不变。已有容器需要重新拉取并重建，保留数据卷。
